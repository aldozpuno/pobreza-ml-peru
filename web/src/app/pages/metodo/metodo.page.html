Validación temporal

El modelo nunca se evalúa con un año que haya usado antes. Cada pliegue entrena con los años anteriores, calibra las probabilidades y elige el umbral con el siguiente, y se evalúa con el que sigue. La prueba final repite el esquema con {{ anios().at(-1) }}, que no se usa para ninguna decisión.

Hogares entrevistados en más de un año

Un hogar se marca como repetido si responde que fue entrevistado el año anterior (pregunta PANEL del módulo 100) o si su llave CONGLOME–VIVIENDA–HOGAR ya apareció en un año anterior. Así se puede evaluar el modelo también solo con hogares nuevos.

En 2017 no hay año anterior en la base, por eso solo cuenta la pregunta PANEL.

Variables que el modelo no puede ver

Se excluyen las variables que definen la pobreza o se calculan con el gasto o el ingreso: con ellas el modelo acertaría sin aprender nada útil.
